 Pesquisa de Opinião - TudoWeb

 Sobre o projeto

Este projeto foi desenvolvido em Python para realizar uma pesquisa de opinião com clientes da empresa de marketing TudoWeb.

O programa coleta o nome, a idade e a opinião dos entrevistados sobre o atendimento prestado.

 Opções de atendimento

- 1 - EXCELENTE
- 2 - BOM
- 3 - RUIM

 Funcionamento

O programa utiliza uma estrutura de repetição para realizar a pesquisa com 50 entrevistados.

Também são utilizadas estruturas de decisão para verificar a opinião informada e contabilizar as respostas classificadas como EXCELENTE e RUIM.

 Tecnologias utilizadas

- Python
- Visual Studio Code

 Teste

Foram realizados testes com 10 entrevistados para verificar o funcionamento do programa.

Durante o teste foram verificadas as contagens das respostas EXCELENTE e RUIM.
